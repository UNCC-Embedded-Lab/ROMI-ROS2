# Romi32U4 Firmware

Store class-approved Arduino firmware for the Pololu Romi 32U4 here.

Current expected sketch path:

- `RomiRPiSlaveDemo/RomiRPiSlaveDemo.ino`

Flashing summary:

1. Install Arduino IDE.
2. Install Pololu board support URL:
   `https://files.pololu.com/arduino/package_pololu_index.json`
3. Install Romi32U4 Arduino library.
4. Open and upload `RomiRPiSlaveDemo.ino` to the Romi 32U4 control board.
